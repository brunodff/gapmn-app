🔖 Bookmarklet — instalar o robô

Arraste o botão abaixo para a sua barra de favoritos. Depois, abra o ComprasNet e clique nele para iniciar o robô.

📋 CNET Bot
Arraste este botão para a barra de favoritos.
No ComprasNet, clique para abrir o painel do robô.

🚀 Passo a passo

  1. Acesse cnetmobile.estaleiro.serpro.gov.br
  2. Clique no favorito CNET Bot na barra
  3. Configure UASG e Apps Script URL
  4. Clique ⟳ PNCP — importa lista de processos
  5. Cole os números no campo Processos → ▶ Executar
  6. O robô lê propostas por item e salva uma aba por processo
  7. Volte aqui, clique ↺ Recarregar — novos processos aparecem

⚙️ Apps Script — cole na planilha

Na planilha: Extensões → Apps Script → apague tudo → cole → salve → Implantar → Nova implantação → App da Web → Acesso: Qualquer pessoa → copie a URL.

↑ Clique para copiar

📡 Fonte de dados

Os dados são lidos diretamente do Supabase (tabela cnet_propostas).
Execute o Bot CNET para raspar os processos no ComprasNet — ele salva automaticamente no Supabase.
Clique ↺ Recarregar no cabeçalho para atualizar o dashboard após uma execução do bot.
