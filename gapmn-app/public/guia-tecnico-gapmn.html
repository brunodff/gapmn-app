1. O que é um Aplicativo Web?

Um aplicativo web é um programa que roda dentro do navegador (Chrome, Edge, Firefox), em vez de ser instalado no computador como um programa comum. Quando você acessa gapmn.app, o navegador baixa o aplicativo de um servidor remoto e o executa localmente — exatamente como o seu navegador já faz com qualquer site.

A diferença entre um "site" e um "aplicativo web" é apenas de complexidade: o site exibe informações estáticas; o aplicativo permite que o usuário faça coisas (logar, salvar dados, clicar, filtrar, importar arquivos).

🏗 Analogia
Pense em um aplicativo web como um livro que se escreve sozinho conforme você lê: o navegador é o leitor, o servidor é a gráfica que entrega as páginas, e o JavaScript é a caneta invisível que preenche e muda o conteúdo em tempo real.

Como o navegador funciona

Quando você digita gapmn.app e pressiona Enter, acontece uma sequência de eventos em milissegundos:

  1. DNS: o navegador pergunta a um servidor de nomes "qual é o endereço IP do gapmn.app?"
  2. TCP/HTTPS: o navegador abre uma conexão criptografada com esse IP
  3. Requisição HTTP: o navegador pede o arquivo index.html
  4. Resposta: o servidor envia o HTML, que referencia arquivos JS e CSS
  5. Execução: o navegador lê o HTML, baixa os demais arquivos e executa o JavaScript
  6. Renderização: a interface aparece na tela

Todo esse processo leva tipicamente menos de 2 segundos. No GAPMN, após esse carregamento inicial, o aplicativo consulta o Supabase (banco de dados) para buscar os dados do usuário logado.

2. HTML — A Estrutura

HTML (HyperText Markup Language) é a linguagem que define o quê existe na página: títulos, parágrafos, botões, tabelas, formulários. Não define cores nem posições — só diz o que cada coisa é. 

<!-- Isso é HTML -->
<div class="card">
  <h2>Título do Card</h2>
  <p>Um parágrafo de texto.</p>
  <button>Clique aqui</button>
</div>

Cada par <tag>...</tag> é um elemento. O navegador converte todos esses elementos em uma árvore chamada DOM (Document Object Model) — uma representação em memória de toda a página, que o JavaScript pode ler e modificar a qualquer momento.

📌 No GAPMN
Cada componente React (ex.: o card de uma NE) gera HTML dinamicamente. Você nunca escreve HTML estático para dados do banco — o React cria o HTML a partir dos dados que chegam do Supabase.

3. CSS — O Visual

CSS (Cascading Style Sheets) define a aparência: cores, fontes, tamanhos, espaçamentos, posições, sombras, gradientes. Opera sobre os elementos HTML selecionando-os por classe (.card), por tipo (button) ou por identificador (#menu). 

/* Seleciona todos os elementos com class="card" */
.card {
  background: #f0f4ff;
  border-radius: 8px;
  padding: 16px;
  box-shadow: 0 2px 8px rgba(0,0,0,0.1);
}

O "Cascading" (em cascata) do nome significa que regras mais específicas sobrescrevem regras mais gerais. Se você definir uma cor para body e outra para .card p, o parágrafo dentro do card usa a segunda regra.

🎨 No GAPMN
O GAPMN usa Tailwind CSS (ver seção 8), que substitui arquivos CSS manuais por classes prontas diretamente no HTML — ex.: bg-sky-100 rounded-xl p-4. O CSS manual só aparece em elementos muito específicos, como o documento que você está lendo agora.

4. JavaScript — O Comportamento

JavaScript (JS) é a linguagem de programação do navegador. É ela que torna a página dinâmica: responde a cliques, faz cálculos, busca dados de servidores, modifica o DOM em tempo real. É a única linguagem que roda nativamente dentro do navegador.

Conceitos fundamentais

Variáveis

Uma variável é uma caixa com nome que guarda um valor.

const nome = "Bruno";          // valor fixo (não muda)
let   contador = 0;            // valor que pode mudar
contador = contador + 1;       // agora contador = 1

Funções

Uma função é um bloco de código com nome que pode ser chamado várias vezes.

function somar(a, b) {
  return a + b;
}

const resultado = somar(3, 4);  // resultado = 7

Arrays e Objetos

// Array: lista ordenada de itens
const nes = ["2026NE000001", "2026NE000002", "2026NE000003"];
nes[0];  // "2026NE000001" (índice começa em 0)

// Objeto: conjunto de propriedades nomeadas
const empenho = {
  ne_siafi: "2026NE000001",
  valor: 102024.70,
  fornecedor: "Prime Consultoria"
};
empenho.valor;  // 102024.70

Async / Await — código assíncrono

Quando o navegador busca dados no banco de dados (Supabase), ele não pode travar e esperar — o usuário ficaria com a tela congelada. Por isso o JavaScript usa código assíncrono: o programa continua rodando enquanto espera a resposta, e uma função especial é chamada quando os dados chegam. 

// async/await: jeito moderno de lidar com operações demoradas
async function buscarEmpenhos() {
  const resposta = await fetch('https://meuservidor.com/empenhos');
  const dados = await resposta.json();
  // só chega aqui DEPOIS que os dados chegaram
  console.log(dados);
}
💡 Por que isso importa no GAPMN
Toda comunicação com o Supabase (buscar NEs, salvar solicitações, atualizar subprocessos) é assíncrona. Se uma chamada falha, o GAPMN trata o erro silenciosamente — sem derrubar a tela — usando blocos try/catch ao redor dos await.

5. TypeScript — JavaScript com Segurança de Tipos

TypeScript (TS) é JavaScript com um sistema de tipos. Você declara explicitamente que tipo de valor cada variável pode ter (string, number, boolean, Date etc.), e o compilador avisa se você tentar misturar tipos incompatíveis — antes mesmo de rodar o código. 

// JavaScript puro — sem proteção:
function calcularJuros(valor, taxa) {
  return valor * taxa;   // e se taxa vier como "5%" (texto) por acidente?
}

// TypeScript — com proteção:
function calcularJuros(valor: number, taxa: number): number {
  return valor * taxa;   // compilador garante que ambos são números
}

Interfaces — descrevendo a forma dos dados

Uma interface descreve o formato de um objeto. No GAPMN, cada tabela do banco tem uma interface correspondente no TypeScript: 

// Descreve como é uma linha da tabela de empenhos
interface EmpenhoSeo {
  id:                 string;
  nota_empenho:       string;        // ex: "2026NE000001"
  valor:              number | null;  // pode ser nulo
  indicador_lotacao:  string | null;
  responsavel:        string | null;
}
🔧 Como o TypeScript é usado no projeto
Os arquivos do GAPMN têm extensão .tsx (TypeScript + JSX/React) ou .ts. O comando npm run build compila todo o código TypeScript para JavaScript puro antes de publicar. Erros de tipo são detectados com npx tsc --noEmit.

6. React — Interfaces Reativas

React é uma biblioteca JavaScript criada pelo Facebook que permite construir interfaces a partir de componentes — pedaços reutilizáveis de interface que gerenciam seu próprio estado e atualizam a tela automaticamente quando os dados mudam.

O que é um componente?

Um componente é uma função que recebe dados (chamados props) e retorna HTML. É como um "carimbo": você define uma vez e usa quantas vezes quiser. 

// Componente simples que mostra uma NE
function CardNE({ ne_siafi, valor }: { ne_siafi: string; valor: number }) {
  return (
    <div className="card">
      <strong>{ne_siafi}</strong>
      <span>R$ {valor.toFixed(2)}</span>
    </div>
  );
}

// Usando o componente:
<CardNE ne_siafi="2026NE000001" valor={102024.70} />

Estado — useState

O estado é um dado que, quando muda, faz o componente se redesenhar automaticamente. O hook useState cria um estado: 

import { useState } from "react";

function Filtro() {
  // busca = valor atual; setBusca = função para mudar o valor
  const [busca, setBusca] = useState("");

  return (
    <input
      value={busca}
      onChange={e => setBusca(e.target.value)}
      placeholder="Buscar NE..."
    />
  );
}

Toda vez que setBusca é chamado, o React redesenha o componente com o novo valor — e você vê o campo de texto atualizado instantaneamente, sem recarregar a página.

Efeitos — useEffect

O useEffect executa um bloco de código quando o componente aparece na tela (ou quando um dado muda). É usado para buscar dados do banco assim que a página carrega: 

import { useEffect, useState } from "react";

function ListaEmpenhos() {
  const [empenhos, setEmpenhos] = useState([]);

  useEffect(() => {
    // Roda quando o componente aparece na tela
    supabase
      .from("empenhos_seo")
      .select("*")
      .then(({ data }) => setEmpenhos(data ?? []));
  }, []);  // [] = roda só uma vez

  return <ul>{empenhos.map(e => <li>{e.nota_empenho}</li>)}</ul>;
}

Memoização — useMemo

O useMemo memoriza o resultado de um cálculo pesado e só o recalcula quando os dados de entrada mudam. Sem ele, o cálculo rodaria a cada redesenho (que pode acontecer centenas de vezes por segundo): 

const sePendentes = useMemo(() => {
  // Filtra SEs que ainda não têm NE emitida — pode ser cálculo lento
  return solicitacoes.filter(s => !neEmitidas.has(s.numero));
}, [solicitacoes, neEmitidas]);  // recalcula só quando esses dois mudam
📌 No GAPMN
O componente GerenciamentoEmpenhos usa vários useMemo encadeados: busca os dados brutos do Supabase, filtra por ano, cruza planilha com SILOMS, calcula pendentes, calcula estatísticas — tudo em memória, sem nova chamada ao banco.

JSX — HTML dentro do JavaScript

O código que parece HTML dentro das funções React é JSX — uma extensão de sintaxe que o compilador converte em chamadas JavaScript. Não é HTML real; é açúcar sintático: 

// JSX (o que você escreve):
<div className="card">Olá</div>

// JavaScript real (o que o compilador gera):
React.createElement("div", { className: "card" }, "Olá")

Note: em JSX usa-se className em vez de class (porque class é palavra reservada do JavaScript).

7. Vite — O Motor de Build

Vite é a ferramenta que transforma os arquivos .tsx e .ts do projeto em arquivos JavaScript, CSS e HTML que o navegador entende.

O que ele faz

  • Compilação: converte TypeScript → JavaScript
  • Bundling: junta dezenas de arquivos em poucos arquivos otimizados
  • Minificação: remove espaços, comentários e encurta nomes de variáveis para reduzir tamanho
  • Hot Module Replacement (HMR): durante o desenvolvimento, atualiza só o componente alterado em milissegundos, sem recarregar a página inteira
ComandoO que faz
npm run devInicia servidor local de desenvolvimento (localhost:5173) com HMR
npm run buildCompila e empacota tudo para a pasta dist/
npm run previewServe a pasta dist/ localmente para testar a versão final

8. Tailwind CSS — Estilo Utilitário

Tailwind é um framework CSS que fornece centenas de classes pequenas e específicas em vez de componentes prontos. Em vez de criar um arquivo .css com regras, você aplica as classes diretamente no HTML: 

<!-- Sem Tailwind (CSS separado): -->
<div class="card">...

<!-- Com Tailwind (tudo inline): -->
<div class="bg-sky-50 rounded-2xl border border-sky-200 p-6 shadow-sm">...

Cada classe tem um efeito preciso e previsível: bg-sky-50 é uma cor específica de azul claro, rounded-2xl é um arredondamento de 16px, p-6 é um padding de 24px (6 × 4px de escala base).

📐 Escala do Tailwind
Tailwind usa escala em múltiplos de 4px: p-1=4px, p-2=8px, p-4=16px, p-6=24px, p-8=32px. As cores têm gradações numéricas: sky-50 (mais claro) → sky-900 (mais escuro).

9. Banco de Dados e SQL

Um banco de dados relacional organiza informações em tabelas, como planilhas Excel, mas com regras rígidas de estrutura, busca eficiente e relacionamentos entre tabelas.

Conceitos básicos

  • Tabela: conjunto de linhas (registros) e colunas (campos). Ex.: empenhos_seo
  • Linha (row): um registro individual. Ex.: uma NE específica
  • Coluna (column): um atributo. Ex.: nota_empenho, valor, responsavel
  • Chave primária (PK): coluna que identifica unicamente cada linha. Geralmente um id automático (UUID)
  • Chave estrangeira (FK): coluna em uma tabela que aponta para uma linha em outra tabela

SQL — a linguagem do banco

SQL (Structured Query Language) é a linguagem para consultar e manipular bancos de dados. Os quatro comandos fundamentais: 

-- Buscar todos os empenhos de 2026
SELECT nota_empenho, valor, responsavel
FROM   empenhos_seo
WHERE  nota_empenho LIKE '2026NE%'
ORDER BY nota_empenho;

-- Inserir um novo registro
INSERT INTO empenhos_seo (nota_empenho, valor, responsavel)
VALUES ('2026NE000999', 50000.00, 'Bruno');

-- Atualizar um registro existente
UPDATE empenhos_seo
SET    responsavel = 'Anne'
WHERE  nota_empenho = '2026NE000999';

-- Deletar um registro
DELETE FROM empenhos_seo
WHERE  nota_empenho = '2026NE000999';

O banco de dados do GAPMN usa PostgreSQL, um dos sistemas de banco de dados mais robustos e confiáveis do mundo, mantido como software livre há mais de 30 anos.

10. Supabase — O Backend do GAPMN

Supabase é um serviço de "Backend as a Service" (BaaS): ele fornece banco de dados PostgreSQL, autenticação de usuários, armazenamento de arquivos e APIs automáticas — tudo pronto, sem precisar programar um servidor.

🏗 Analogia
Se o banco de dados fosse um almoxarifado, o Supabase seria o almoxarifado já montado, com câmeras de segurança (autenticação), fichas de controle de acesso (RLS), balcão de atendimento (API) e registro automático de quem entrou e saiu — sem você precisar construir nada disso.

Como o GAPMN usa o Supabase

O Supabase gera automaticamente uma API REST para cada tabela do banco. O cliente JavaScript do Supabase transforma esse código: 

const { data, error } = await supabase
  .from("empenhos_seo")
  .select("nota_empenho, valor, responsavel")
  .like("nota_empenho", "2026NE%")
  .order("nota_empenho");

…em uma requisição HTTP para:

GET https://seu-projeto.supabase.co/rest/v1/empenhos_seo
    ?select=nota_empenho,valor,responsavel
    ¬a_empenho=like.2026NE%25
    &order=nota_empenho

Variáveis de ambiente

O endereço e a chave de acesso do Supabase ficam no arquivo .env (não versionado no Git por segurança): 

VITE_SUPABASE_URL=https://xxxxxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciO...

A anon key é uma chave pública — qualquer pessoa poderia vê-la. A segurança real vem do RLS (próxima seção), que garante que mesmo com a chave, você só acessa o que tem permissão.

11. Autenticação e Segurança (RLS)

Autenticação — como o login funciona

Quando o usuário digita email e senha, o Supabase verifica as credenciais e retorna um JWT (JSON Web Token) — um token criptografado que prova a identidade do usuário. Esse token é salvo no navegador e enviado em todas as requisições subsequentes ao banco.

🔐 O que é um JWT
Um JWT é um texto longo codificado (começa com "eyJ...") que contém o ID do usuário, quando o token foi criado e quando expira — tudo assinado criptograficamente. O servidor pode verificar a autenticidade sem precisar consultar o banco a cada requisição.

Row Level Security (RLS)

RLS é um mecanismo do PostgreSQL que aplica regras de acesso diretamente no banco de dados, linha a linha. Mesmo que alguém tente acessar os dados diretamente pela API (sem passar pelo aplicativo), as políticas RLS bloqueiam o acesso não autorizado. 

-- Exemplo de política RLS: usuários só veem seus próprios registros
CREATE POLICY "usuarios_proprios_dados"
  ON chat_messages
  FOR ALL
  USING (user_id = auth.uid());
  -- auth.uid() retorna o ID do usuário logado no token JWT

Sistema de perfis (roles) no GAPMN

12. APIs e Comunicação HTTP

Uma API (Application Programming Interface) é um conjunto de regras que define como dois programas conversam entre si. No contexto web, é um servidor que responde perguntas específicas via HTTP.

HTTP — o protocolo da web

Toda comunicação na web usa HTTP (ou HTTPS, a versão criptografada). Uma requisição HTTP tem:

  • Método: GET (buscar), POST (criar), PATCH (atualizar parcialmente), DELETE (apagar)
  • URL: o endereço do recurso
  • Headers: metadados (ex.: chave de autenticação, tipo do conteúdo)
  • Body: dados enviados (só em POST/PATCH)

APIs usadas no GAPMN

Exemplo: consultando o Banco Central

// Busca a variação acumulada do IPCA entre duas datas
const url = `https://api.bcb.gov.br/dados/serie/bcdata.sgs.433/dados`

// dados = [{ data: "02/01/2023", valor: "0.53" }, ...]

13. Os Bookmarklets — Robôs do Navegador

Um bookmarklet é um favorito do navegador cujo endereço, em vez de uma URL normal, é um pequeno programa JavaScript que começa com javascript:. Ao clicar no favorito, o navegador executa esse código na página aberta.

Como o GAPMN injeta os robôs

Os robôs do GAPMN são scripts grandes demais para caber no favorito. Por isso o bookmarklet faz apenas uma coisa: cria uma tag <script> que baixa o robô do servidor: 

// O bookmarklet que você salva no favorito:
javascript:(function(){
  var s = document.createElement('script');
  s.src = 'https://gapmn.app/cnet-bot.js?v=' + Date.now();
  document.body.appendChild(s);
})();

O ?v='+Date.now() força o navegador a sempre baixar a versão mais recente (sem usar cache), adicionando um número diferente (timestamp) a cada clique.

O que o robô pode fazer na página

Por rodar na mesma aba que o portal governamental, o robô tem acesso total ao DOM daquela página e às credenciais da sessão já logada. Ele pode:

  • Ler textos de qualquer elemento (element.innerText)
  • Clicar em botões (button.click())
  • Preencher campos de formulário (input.value = "texto")
  • Navegar entre páginas (window.location.href = "nova-url")
  • Fazer requisições ao Supabase para salvar os dados coletados

Persistência entre recarregamentos — sessionStorage

Quando o portal recarrega a página (como o Portal de Contratos faz entre etapas da Minuta de Empenho), todo o estado JavaScript é perdido. O Robô do Empenho resolve isso com sessionStorage — um armazenamento local no navegador que sobrevive a recarregamentos dentro da mesma aba: 

// Salvar dados antes do recarregamento:
sessionStorage.setItem('empBotStep', '3');
sessionStorage.setItem('empBotData', JSON.stringify(dadosExtraidos));

// Recuperar após recarregar:
const step = sessionStorage.getItem('empBotStep');
const data = JSON.parse(sessionStorage.getItem('empBotData'));

14. PDF.js — Lendo PDFs no Navegador

PDF.js é uma biblioteca JavaScript criada pela Mozilla (fabricante do Firefox) que lê e renderiza arquivos PDF diretamente no navegador, sem plugin externo. O Robô do Empenho a usa para extrair o texto da Solicitação de Empenho.

Como a extração funciona

Um PDF não é um documento de texto — é um conjunto de instruções de posicionamento: "coloque o texto 'CNPJ' nas coordenadas (X=50, Y=300)". O PDF.js lê essas instruções e reconstrói o conteúdo: 

// 1. Carregar o arquivo PDF (buffer de bytes)
const pdfDoc = await pdfjsLib.getDocument({ data: buffer }).promise;

// 2. Ler a primeira página
const page = await pdfDoc.getPage(1);

// 3. Extrair todos os fragmentos de texto com posição X,Y
const content = await page.getTextContent();
content.items.forEach(item => {
  const x = item.transform[4];  // posição horizontal
  const y = item.transform[5];  // posição vertical
  console.log(item.str, `@ (${x}, ${y})`);
});

A posição X é especialmente importante para identificar colunas de tabelas — como o campo SUB (subelemento) da SE, que aparece em uma coluna específica sem label próxima.

15. Deploy e Infraestrutura

Deploy é o ato de publicar o aplicativo em um servidor público para que outros possam acessá-lo. O GAPMN usa dois serviços diferentes para hospedar partes distintas do sistema.

Vercel — hospedagem do app e dos bookmarklets

Vercel é uma plataforma de hospedagem otimizada para aplicações React/Vite. Quando o código é enviado via vercel deploy --prod, a Vercel:

  1. Executa o build (npm run build)
  2. Publica os arquivos gerados em sua CDN global (servidores em todo o mundo)
  3. Configura o domínio gapmn.app para apontar para esses arquivos
  4. Configura HTTPS automaticamente
🌐 CDN — Content Delivery Network
Uma CDN mantém cópias dos seus arquivos em dezenas de servidores ao redor do mundo. Quando um usuário em Manaus acessa gapmn.app, ele baixa os arquivos do servidor CDN mais próximo (ex.: São Paulo), não dos EUA — tornando o carregamento mais rápido.

Netlify — hospedagem alternativa

O GAPMN também tem configuração para a Netlify, outra plataforma similar à Vercel, usada como alternativa ou para funções serverless específicas.

O arquivo vercel.json

Este arquivo na raiz do projeto instrui a Vercel sobre como servir o app: 

{
  "rewrites": [
    { "source": "/(.*)", "destination": "/index.html" }
  ]
}

Isso diz: "qualquer URL que não corresponda a um arquivo existente, sirva o index.html". Isso é necessário porque o React Router controla as rotas no lado do cliente — o servidor não precisa conhecer /setor ou /orcamento; ele sempre entrega o mesmo index.html e o React cuida do resto.

Fluxo de uma ação típica — usuário filtra empenhos

  1. Usuário digita "2026NE000463" no campo de busca da tela de Empenhos
  2. React chama setBusca("2026NE000463") → estado muda
  3. React redesenha o componente com o novo estado
  4. O useMemo filtrado recalcula: filtra os dados já em memória
  5. A tabela exibe apenas as linhas que contêm "2026NE000463"
  6. Nenhuma chamada ao banco é feita — os dados já estavam em memória desde o carregamento inicial

Fluxo do Robô CNET — extração de propostas

  1. Usuário abre o ComprasNet com o pregão no navegador
  2. Usuário clica no favorito (bookmarklet)
  3. O bookmarklet cria um <script> que baixa cnet-bot.js de gapmn.app
  4. O script roda: exibe overlay, lê os itens da página via DOM
  5. Para cada item: clica no botão "Visualizar propostas", aguarda carregamento, extrai dados
  6. Ao concluir todos os itens: faz POST para o Supabase salvando todas as linhas de uma vez
  7. Usuário pode ver os dados no Google Sheets via integração configurada

17. Glossário

API
Interface de comunicação entre programas. Na web, geralmente um servidor que responde a requisições HTTP com dados em formato JSON.
Array
Lista ordenada de itens em JavaScript: ["a", "b", "c"]. O índice começa em 0.
Async / Await
Palavras-chave do JavaScript para lidar com operações demoradas (como buscar dados) sem travar a interface do usuário.
BaaS
Backend as a Service — serviço que fornece infraestrutura de servidor pronta (banco, autenticação, armazenamento) sem precisar programar um servidor do zero.
Bookmarklet
Favorito de navegador cujo endereço é um programa JavaScript. Ao clicar, executa código na página atual.
Build
Processo de compilar, empacotar e minificar o código-fonte para produzir arquivos prontos para publicação.
CDN
Rede de servidores distribuídos globalmente que entrega arquivos estáticos ao usuário pelo servidor mais próximo geograficamente.
Componente (React)
Função JavaScript que recebe dados e retorna HTML. Unidade básica de construção de interfaces no React.
CSS
Linguagem que define a aparência visual dos elementos HTML: cores, fontes, tamanhos, posições.
Deploy
Ato de publicar uma versão do aplicativo em um servidor de produção acessível ao público.
DOM
Representação em memória de todos os elementos HTML de uma página, que o JavaScript pode ler e modificar.
HTML
Linguagem de marcação que define a estrutura e o conteúdo de páginas web.
HTTPS
Versão criptografada do protocolo HTTP. Toda comunicação é cifrada, impedindo interceptação por terceiros.
Interface (TypeScript)
Definição da estrutura esperada de um objeto: quais campos tem, de qual tipo é cada campo.
JavaScript
A linguagem de programação nativa do navegador. Torna as páginas dinâmicas e interativas.
JSX
Extensão de sintaxe do JavaScript usada no React que permite escrever código similar a HTML dentro das funções.
JSON
Formato de texto para representar objetos JavaScript. Padrão universal de troca de dados entre sistemas.
JWT
Token criptografado que prova a identidade de um usuário. Gerado no login, enviado em todas as requisições subsequentes.
localStorage / sessionStorage
Armazenamentos locais no navegador. localStorage persiste após fechar o browser; sessionStorage dura só enquanto a aba está aberta.
PostgreSQL
Sistema de banco de dados relacional avançado. Suporta JSON, triggers, RLS e extensões poderosas.
Props
Parâmetros passados para um componente React — como argumentos de uma função.
React
Biblioteca JavaScript para construir interfaces baseadas em componentes com atualização automática quando o estado muda.
RLS
Row Level Security — mecanismo do PostgreSQL que aplica regras de acesso linha a linha, diretamente no banco de dados.
SQL
Linguagem padrão para consultar e manipular bancos de dados relacionais.
Supabase
Plataforma BaaS que combina PostgreSQL, API REST automática, autenticação e armazenamento de arquivos.
TypeScript
Superset do JavaScript que adiciona tipos estáticos. Detecta erros em tempo de desenvolvimento, antes de rodar o código.
useMemo
Hook do React que memoriza o resultado de um cálculo pesado, recalculando só quando as dependências mudam.
useEffect
Hook do React que executa código quando o componente aparece na tela ou quando uma dependência muda. Usado para buscar dados.
useState
Hook do React que cria um estado local: um valor que, ao mudar, redesenha o componente automaticamente.
Vercel
Plataforma de hospedagem otimizada para React/Next.js. Faz build e deploy automáticos com CDN global.
Vite
Ferramenta de build rápida para projetos JavaScript modernos. Compila TypeScript, empacota módulos e serve o app em desenvolvimento.
